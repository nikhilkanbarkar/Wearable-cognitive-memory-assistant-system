About Cognitive Assist

A Raspberry Pi wearable that recognises faces entirely offline, speaks the result aloud, and logs every attempt to a local database that a caregiver can browse from any phone or laptop on the same Wi-Fi.

Each recognition is a single, deliberate button press, not continuous scanning. The wearer hears the person's name through Bluetooth earbuds, or a polite note that the face is not recognised, while the caregiver reviews the full history here.

Everything runs on the device. There is no cloud service, no internet dependency and no external API.

Use cases

  • Helping someone recall who they are talking to
  • Letting caregivers review recent encounters
  • Checking unfamiliar faces that were captured

Key technologies

  • Raspberry Pi 4B
  • YuNet
  • ArcFace
  • Piper TTS
  • SQLite
  • Flask

How it works

  1. Button pressOne press starts one attempt.
  2. Camera captureA short burst of frames is taken.
  3. Face detectionYuNet picks the best face.
  4. Face matchingArcFace embedding compared with registered people.
  5. Audio / OLED feedbackResult is spoken and shown on the display.
  6. SQLite loggingKnown, unknown, no-face and error events are saved.
  7. Caregiver dashboardHistory is reviewed on this page.

Key capabilities

Offline processing

Detection, matching and speech all run on the Pi, with no internet connection needed.

Private local storage

Events, unknown-face images and embeddings stay on the device and are reachable only on the local network.

Spoken identification

Names are announced through Bluetooth earbuds using offline text-to-speech.

Caregiver monitoring

Review history, filter events and mark unknown faces as confirmed or dismissed.
